# Word Jewel Quest (영어 단어 보석 매치 게임)

보석 매치(Match-3) 방식과 초등/기초 영어 단어 학습을 결합한 에듀테크 웹 게임입니다.

🎮 **실시간 플레이 (GitHub Pages)**: [https://eversunk2-tech.github.io/card-lab1/jewel/](https://eversunk2-tech.github.io/card-lab1/jewel/)

---

## 🌟 주요 기능 및 최신 업데이트

1. **마법의 힌트 보석 (Wildcard Joker Gem: `?`)**:
   - 4글자, 5글자 이상 또는 다중 단어 미션에서 보드 군데군데에 무지개빛 힌트 보석(`?`)이 자동 주입됩니다.
   - 인접한 보석과 자유롭게 자리를 바꾼 뒤, 목표 단어 철자를 원클릭으로 선택하거나 직접 알파벳을 입력하여 원하는 글자로 즉시 변신시켜 단어를 쉽게 완성할 수 있습니다.
2. **시원하게 2배 확대된 결과 창 & 점수 표시**:
   - 미션 완료 결과 창이 2배로 커져 한눈에 성취감과 단어 뜻, 원어민 발음, 최종 점수를 확인할 수 있습니다.
   - 실행 창의 SCORE 점수 글자 크기도 2배로 확대되어 콤보와 점수 획득이 눈에 확 들어옵니다.
3. **와이드 스크린 2-컬럼 반응형 레이아웃**:
   - PC/노트북 화면에서 좌측 패널 + 우측 대형 보드로 빈칸 없이 꽉 찬 뷰포트를 제공하며, 모바일 화면에서는 1-컬럼으로 자동 적응합니다.
4. **단계별 단어 코스 사전 설정 (교사 모드)**:
   - 교사가 초급/중급/고급 단계별로 가르치고자 하는 단어들을 쉼표로 입력하면 미션이 무제한 자동 생성됩니다.
   - 제한 시간, 더미 글자 등도 자유롭게 조절 가능합니다.
5. **듀얼 단어 미션 보드 보존**:
   - 2개 이상 단어 미션에서 1번째 단어를 맞추어도 보드 타일이 터지거나 리필되지 않고 그대로 유지되어 2번째 단어로 매끄럽게 이어집니다.
6. **웹 오디오 & 브라우저 Speech Synthesis 원어민 음성 낭독**:
   - 단어 완성 시 해당 위치 스포트라이트와 함께 철자별 순차 낭독 및 전체 단어 음성 발음 재생.
