## 한 문장

초등학생이 영어 단어 공부를 "한 판 더!" 하고 싶은 놀이로 느끼도록, 옛날 게임기와 포스터처럼 크고 굵고 재밌는 화면으로 맞이한다.

## 스타일 (주 / 보조)

- **주: 볼드 레트로 · B 방향(레트로 OS)** — 굵은 검은 선, 딱딱한 그림자, 줄무늬 제목줄이 있는 옛날 컴퓨터 창(`LOGIN.EXE`, `READY.EXE`)
- **포인트: C 방향(픽셀)** — 숫자와 영문 라벨에만 도트 글꼴(Silkscreen)을 쓴다. 한글 본문에는 쓰지 않는다.

## 화면 목록

| 구분 | 화면 | 하는 일 |
|---|---|---|
| 메인 | 1. 인트로 | 게임 제목 포스터, 학생 로그인(주 버튼), 교사 로그인(보조 버튼), 오늘의 단어 듣기 |
| 세부 | 2. 학생 로그인 | 구글 계정 / 교사가 만든 아이디 두 가지 방법, 빈 칸 오류 상태 |
| 세부 | 3. 교사 로그인 | 구글 / 이메일 로그인, 대시보드에서 할 수 있는 일 안내 |
| 세부 | 4. 게임 선택 | 게임 카트리지 4개 중 고르기 → 오른쪽 준비 창(READY.EXE)이 바뀜, 연습 모드·효과음 끄기 |
| 세부 | 5. 교사 대시보드 | 참여·정답률 요약, 학생별 기록 표, 자주 틀린 단어 |

- 원색은 면으로 크게 쓴다. 빨강·노랑·초록 위 글자는 검정, 코발트·밤색 위 글자만 흰색.
- 위험·오류는 빨강 + 느낌표 아이콘 + 문장. 색만으로 알리지 않는다.

## 글꼴

| 역할 | 글꼴 | 비고 |
|---|---|---|
| 제목 | Gasoek One | 포스터 제목 `clamp(56px, 10.4vw, 150px)`, 줄 간격 0.9 |
| 숫자·영문 라벨 | Silkscreen | 점수, 창 이름, `MEMORY` 같은 라벨. 한글 없음 |
| 본문·영어 단어 | IBM Plex Sans KR 500/600/700 | 본문 16–20px, 줄 간격 1.65 |

- 크기 단계: 12 · 14 · 16 · 20 · 28 · 40 · 64 · 96 (+ 포스터 제목)
- 강조 단어는 노란 채움 + 검은 외곽선(`-webkit-text-stroke`) + 하드 그림자.
- `word-break: keep-all`, 숫자는 `tabular-nums`.

## 간격과 모양

- 4px 단위: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64
- 테두리 3px 검정. 모서리: 버튼·입력 6px, 카트리지 12px(위) / 6px(아래), 창 4px.
- 하드 섀도(흐림 없음): `--hs-1` 4px, `--hs-2` 6px, `--hs-3` 10px.

## 빛과 층

- **광원은 왼쪽 위 하나.** 하드 섀도는 모두 오른쪽 아래로 떨어진다.
- **층 3단계**: 바탕(종이 + 망점 원) / 창·카드(`--hs-2`) / 잠깐 뜨는 것(스티커·말풍선·토스트, `--hs-3`).
- **광택 코팅**: 스티커와 주 버튼 윗부분에 흰 타원 하이라이트.
- **흐르는 빛**: 주 버튼(학생 로그인, 시작하기, START)에 올렸을 때 한 번, 선택된 카트리지에 8초마다 한 번. 이 외에는 쓰지 않는다.
- **주사선**: 밤색 게임 창 안쪽에만 아주 얕게.

## 그림 체계

- 3px 검정 외곽선, 팔레트 안의 단색 채움, 그라데이션 없음, 윗면 하이라이트 하나, 오른쪽 아래 하드 섀도.
- 게임 아이콘: 메모리 = 카드 두 장, 보석 = 깎은 보석, 듣고 고르기 = 스피커, 스피드 퀴즈 = 초시계 + 번개.
- 마스코트 **비트(Bit)**: 옛날 컴퓨터 모양, 화면 속 도트 눈과 계단 모양 웃음. 로그인 화면에만 나온다. (시안 단계 제안, 바꿔도 됨)

## 게임별 표시

| 게임 | 라벨 | 색 | 아이콘 | 학습 영역 |
|---|---|---|---|---|
| 카드 뒤집기 | `01 MEMORY` | yellow | 카드 두 장 | 읽기 |
| 보석 게임 | `02 JEWEL` | night | 깎은 보석 | 단어 |
| 듣고 고르기 | `03 LISTEN` | cobalt | 스피커 | 듣기 |
| 스피드 퀴즈 | `04 SPEED` | red | 초시계 + 번개 | 순발력 |

색만으로 구분하지 않도록 아이콘, 번호 붙은 영문 라벨, 한글 이름을 항상 같이 쓴다.

## 에셋

- 지금은 모두 인라인 SVG와 CSS로 그렸다. 외부 이미지·소리 파일 없음.
- 단어 발음은 브라우저 음성 합성(`speechSynthesis`, en-US)으로 낸다.
- 단어 그림 카드, 효과음, 배경 음악이 필요해지면 `ui-assets-with-gemini` 순서에 따라 목록을 먼저 승인받는다.

## 움직임

- 빠름 120ms / 보통 240ms / 강조 400ms. 딱딱하고 빠르게.
- 버튼: 올리면 2px 떠오르고 그림자가 늘어남, 누르면 그림자 위치까지 내려앉음(120ms).
- 스티커: 통 튀어나오기(240ms, 살짝 넘치는 곡선).
- 오류: 알림 상자가 좌우로 짧게 흔들림(320ms).
- 움직임 줄이기 설정이면 띠 흐름, 흐르는 빛, 튀어나오기, 흔들림을 모두 멈춘다.

## 접근성

- 글자 대비 4.5:1 이상(표 참고). 누를 곳 44×44px 이상, 진짜 `button` / `a` / `input`.
- 포커스는 4px 코발트 외곽선(4px 띄움).
- 게임 선택 화면에 **연습 모드(시간 제한 없음)** 와 **효과음** 켜고 끄기. 상태는 색 + "켜짐/꺼짐" 글자.
- 정답·오답·오류는 색 + 아이콘 + 문장.

## 하지 않을 것

- 흐린 부드러운 그림자, 연한 파스텔, 보라·파랑 그라데이션 배경
- 이모지 아이콘
- 볼드 레트로의 세 방향(A 네오브루탈 / B 레트로 OS / C 픽셀)을 한 화면에 모두 섞기
- 실제 유명 게임·캐릭터를 흉내 낸 그림
- 본문 기울이기 (기울이기는 스티커와 메모 카드만)
