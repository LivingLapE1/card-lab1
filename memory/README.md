# 01 MEMORY · 카드 뒤집기 — 교사용 설치 안내

Fun English의 **01 MEMORY (카드 뒤집기)** 게임입니다. 영어·한글·그림 카드 3장을 찾아 맞춥니다.

- 게임 주소 (GitHub Pages): `https://eversunk2-tech.github.io/card-lab1/memory/?nick=학생이름`
- 메인 화면의 카드 뒤집기 START 버튼은 위 주소로 연결하면 됩니다. 함께 넘길 수 있는 값(`practice`, `sfx`, `bgm`)은 아래 "메인 페이지와 연결하기"를 보세요.
- 이 폴더 안의 파일만 쓰므로 저장소의 다른 게임(보석 게임 등)과 겹치지 않습니다.

## 폴더 구성

| 파일·폴더 | 하는 일 |
|---|---|
| `index.html` | 게임 본체. 브라우저(Chrome, Edge)로 엽니다. |
| `words.js` | 학기별 단어 80개. 단어를 바꾸려면 이 파일을 고칩니다. |
| `config.js` | 반 기록 저장소 주소, 메인 페이지 주소, 학생 이름을 넘겨받는 방법 설정 |
| `images/` | 단어 그림 파일 (`그림_넣는_방법.txt` 참고) |
| `music/` | 배경음악 파일 `bgm.mp3` (없으면 기본 멜로디) |
| `apps-script/Code.gs` | 반 기록 저장소(구글 시트)에 붙여 넣을 코드 |

## 게임 규칙 요약

- 학생은 메인 페이지에서 로그인하고 들어오므로, 게임에는 따로 로그인 화면이 없습니다. 들어오면 바로 학기 선택 화면이 나옵니다.
- 메인 페이지를 거치지 않고 게임 주소로 바로 들어오면 "메인 페이지에서 로그인한 뒤 들어와 주세요" 안내가 나옵니다.

## 메인 페이지와 연결하기

메인 페이지는 아래 두 방법 중 하나로 학생 이름(또는 별명)을 게임에 넘겨주면 됩니다. 설정은 `config.js`에서 합니다.

| 방법 | 메인 페이지에서 할 일 | `config.js` 설정 |
|---|---|---|
| ① 주소에 붙여 넘기기 | 게임 링크를 `.../index.html?nick=07김하늘` 형태로 만듦 | `NICK_PARAM: "nick"` (기본값 그대로) |
| ② 브라우저 저장소로 넘기기 (메인 페이지와 게임이 **같은 사이트 주소**일 때만) | 로그인할 때 `localStorage.setItem("studentName", "07김하늘")` 처럼 저장 | `NICK_STORAGE_KEY: "studentName"` (메인 페이지가 쓴 키 이름) |

- `MAIN_URL`에 메인 페이지 주소를 넣으면 학기 선택 화면에 **← 메인으로** 버튼이 생깁니다.
- 메인 페이지의 게임 선택 화면(READY.EXE)에서 고른 설정도 주소에 붙여 넘길 수 있습니다.

| 붙이는 값 | 뜻 |
|---|---|
| `practice=1` | 연습 모드: 시간 제한 없음. 레벨은 깬 것으로 치지만 점수는 반 순위와 최고 기록에 넣지 않음 |
| `sfx=0` / `sfx=1` | 효과음 끄기 / 켜기 |
| `bgm=0` / `bgm=1` | 배경음악 끄기 / 켜기 |

예: `index.html?nick=07김하늘&practice=1&sfx=0`
- 기록은 넘겨받은 이름으로 저장되므로, 학생마다 이름이 겹치지 않아야 합니다.
- 방법 ①은 이름이 주소창에 보입니다. 실명보다 번호나 별명을 넘기는 것을 권장합니다.
- 화면 디자인은 메인 페이지와 같은 "Fun English" 디자인(card-lab1 저장소의 `design/DESIGN.md`)을 따릅니다.
- 카드는 뒷면 색과 표시로 구분합니다. **파랑 + ABC = 영어**, **노랑 + 가 = 한글**, **빨강 + 그림 아이콘 = 그림**. (초록은 정답 표시에만 씁니다)
- 영어·한글·그림 카드는 구역을 나누지 않고 한 판에 무작위로 섞여 놓입니다.
- 게임 화면 위쪽 안내 줄에 아직 골라야 하는 카드 색이 표시됩니다. 예: "다음: 노랑(한글), 빨강(그림) 카드를 골라요"
- 색깔마다 한 장씩, 모두 3장을 뒤집습니다. 같은 단어면 영어 발음이 나오고 카드가 사라집니다.
- 학기를 고르면 아직 깨지 않은 다음 레벨이 바로 시작됩니다. 레벨 1부터 5까지 순서대로 진행합니다.
- 5레벨을 모두 깬 학생만 그 학기의 레벨을 골라서 다시 연습할 수 있습니다.
- 학기 선택 화면의 **📋 단어·그림 보기**에서 학기별 단어와 그림 파일이 제대로 들어갔는지 확인할 수 있습니다.

| 레벨 | 단어 | 카드 | 제한 시간 | 시작 전 카드 미리 보기 |
|---|---|---|---|---|
| 1 | 2개 | 6장 | 60초 | 없음 |
| 2 | 3개 | 9장 | 90초 | 없음 |
| 3 | 4개 | 12장 | 120초 | 없음 |
| 4 | 5개 | 15장 | 150초 | 3초 |
| 5 | 6개 | 18장 | 180초 | 4초 |

- 레벨 4와 5는 시작할 때 카드 앞면을 모두 보여 주고, 다시 뒤집은 뒤 시간이 흐르기 시작합니다. 미리 보는 동안에는 카드를 누를 수 없습니다.
- 미리 보기 시간은 `index.html`의 `LEVELS` 줄에서 `preview` 숫자를 바꾸면 됩니다. 1~3레벨에 넣고 싶으면 `preview:2`처럼 추가합니다.

- 점수: 한 세트를 맞히면 10점, 연속으로 맞히면 +5점, 레벨을 깨면 남은 시간 1초당 1점
- 한 세트를 맞힐 때마다 남은 시간이 **2초 늘어납니다**. 늘어나는 시간은 `index.html`의 `BONUS_SEC = 2`에서 바꿀 수 있습니다.
- 시간이 끝나면 실패이고, 못 찾은 단어를 보여 준 뒤 **다시하기** 버튼이 나옵니다.

## 반 전체 기록 저장소 만들기 (처음 한 번, 약 10분)

학생들이 서로 다른 태블릿에서 해도 기록이 한곳(구글 시트)에 모이고, **반 순위** 화면에 나옵니다.

1. 선생님 구글 계정으로 [Google 스프레드시트](https://sheets.google.com)에서 **빈 스프레드시트**를 만듭니다. 이름 예: `영어카드게임 기록`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 내용을 모두 지우고, `apps-script/Code.gs` 파일 내용을 그대로 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙️) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한 승인 창이 뜨면 선생님 계정으로 허용합니다.
   ("확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. `config.js`를 메모장으로 열어 따옴표 안에 붙여 넣고 저장합니다.

```js
window.CONFIG = {
  RECORD_URL: "https://script.google.com/macros/s/....../exec"
};
```

8. 게임을 새로고침한 뒤 한 판을 하고, 스프레드시트에 **기록** 탭이 생겨 결과가 쌓이는지 확인합니다.

알아 두실 점
- 시트의 **기록** 탭에서 학생별 기록(시간, 별명, 학기, 레벨, 점수, 성공/실패)을 바로 볼 수 있습니다.
- 학기 초에 기록을 지우려면 **기록** 탭의 2행부터 아래를 삭제하면 됩니다.
- 메인 페이지에서 넘겨받은 이름이 같으면 같은 학생으로 봅니다.
- 다른 기기에서 같은 이름으로 들어가면 깬 레벨을 저장소에서 불러옵니다.
- 인터넷이 잠깐 끊겨도 기록은 기기에 보관했다가 다시 연결되면 보냅니다.
- `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 수정(✏️) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 태블릿과 전자칠판에서 여는 방법

`index.html`은 선생님 PC에서 바로 열 수 있지만, 학생 태블릿에서 열려면 폴더 전체를 인터넷 주소로 올려야 합니다.

- **전자칠판 / 교실 PC**: 폴더를 USB나 PC에 복사하고 `index.html`을 Chrome이나 Edge로 엽니다.
- **학생 태블릿**: 폴더를 웹에 올려 주소를 만든 뒤 QR코드로 나눠 줍니다. 예: GitHub Pages, Netlify Drop(폴더를 끌어다 놓으면 주소가 생김)

## 브라우저 안내

- Chrome이나 Edge를 권장합니다. 영어 발음은 기기에 설치된 영어 음성을 씁니다.
- 처음 화면을 한 번 눌러야 소리가 나는 것은 브라우저 정책입니다.
- 화면 오른쪽 위 🎵(배경음악)와 🔔(효과음) 버튼으로 소리를 따로 켜고 끕니다.
