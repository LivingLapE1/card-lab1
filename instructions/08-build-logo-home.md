# Build 지침 — 왼쪽 위 "Fun English" 로고를 누르면 첫 화면으로

> 담당: Build 서브에이전트 (opus, 추론 강도 high — 공통 함수 하나와 CSS 몇 줄을 바꾸는 작은 작업이라 high로 충분)
> 사용자 요청: 2026-11-14 "각 페이지별로 좌측의 Fun English 글자를 누르면 첫 메인 화면으로 이동하게 해줘"

## 1. 배경

- 메인 웹 앱의 화면 위쪽 왼쪽에 "Fun English" 로고가 있다. 로고는 `js/ui/parts.js`의 `logo()` 한 곳에서 만들고, 6개 화면이 쓴다: 학생 로그인, 교사 로그인, 게임 선택(hud), 게임 자리 화면, 교사 대시보드, 길을 잃었어요.
- 지금 로고는 `<p class="logo">`라서 누를 수 없다.
- 인트로(첫 화면)에는 이 로고가 없다(큰 포스터 제목이 대신한다). 인트로는 고치지 않는다.

## 2. 할 일

1. `logo()`가 **첫 화면(`#/`)으로 가는 링크**를 만들게 바꾼다.
   - 진짜 `<a href="#/">`로 만든다. 화면 낭독기용 이름은 "Fun English 첫 화면으로" (`aria-label` 등). 교사 화면의 `TEACHER` 표시가 있어도 이름은 같다.
   - 모양은 지금과 똑같이 보이게 한다 (글자 색·밑줄 없음·크기·간격 그대로). `.logo`를 쓰는 기존 CSS 규칙(숨김 규칙 포함)이 그대로 맞게 한다.
   - 누를 수 있다는 표시: 포커스 외곽선(기존 `:focus-visible` 규칙), 마우스를 올리면 살짝 반응(예: 2px 떠오름, `@media (hover:hover)` 안에서만, 움직임 줄이기 존중). DESIGN.md의 "하지 않을 것"을 지킨다.
   - 누르는 영역은 44px 이상 높이를 맞춘다.
2. 로그인한 상태에서 눌러도 첫 화면으로 간다. 로그인 상태는 그대로 둔다(로그아웃하지 않는다).
3. 지금 있는 숨김 규칙(좁은 화면에서 로고를 숨기는 `bars.css`, `play.css`의 규칙)은 그대로 둔다.

## 3. 수정 범위 (꼭 지킬 것)

- 고칠 수 있는 파일: `js/ui/parts.js`, `css/bars.css`, 꼭 필요하면 로고를 쓰는 화면 파일(`js/screens/*.js`)과 `css/components.css`.
- `jewel/`, `memory/`, `CLAUDE.md`, `spec.md`, `review.md`, `design/`, `instructions/`는 고치지 않는다.
- git 커밋·푸시·add·reset을 하지 않는다. (작업 폴더에는 이미 stage된 변경이 있다. 그대로 둔다.)

## 4. 확인 방법

바탕화면 폴더에서 띄운 서버는 파일을 못 읽으므로 임시 폴더에 복사해서 띄운다(위치는 작업 요청 메시지에 있다).

```bash
rsync -a --delete --exclude .git "<프로젝트 폴더>/" "<임시 폴더>/build-site/"
cd "<임시 폴더>" && python3 -m http.server 8701 --bind 127.0.0.1 --directory "<임시 폴더>/build-site"
```

- 6개 화면에서 로고를 누르면 인트로(`#/`)로 가는지. 로그인한 뒤 게임 선택·대시보드에서 눌러도 인트로로 가고, 다시 "학생 로그인"을 누르면 로그인 상태라 게임 선택으로 갈 수 있는지(지금 라우터 동작 그대로면 된다).
- 키보드: Tab으로 로고에 갈 수 있고 포커스가 보이고 Enter로 이동하는지.
- 1280px에서 로고 모양이 바꾸기 전과 같은지(위치·크기·색).
- 360 / 768 / 1280px에서 가로 스크롤 없음. `node --check`.
- 서버는 끝나면 끈다. 캐시 주의(강력 새로고침).

## 5. 끝나면 보고할 것 (짧게)
