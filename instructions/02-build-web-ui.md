# Build 지침 — Fun English 웹 UI 골격

> 담당: Build 서브에이전트 (opus, 추론 강도 xhigh)
> 근거: 승인된 `spec.md` (2026-11-14, 12장 질문 1–8 모두 추천안)

## 1. 목표

`spec.md`에 적힌 대로 Fun English 웹 앱의 화면 골격을 만든다. 결과는 GitHub Pages 첫 주소(`https://eversunk2-tech.github.io/card-lab1/`)에서 그대로 열려야 한다.
진짜 로그인, 데이터베이스, 게임 로직은 만들지 않는다 (spec 2.2절).

## 2. 수정 범위 (꼭 지킬 것)

- **만들 것**: spec 4장 파일 트리에서 `★` 표시된 파일 전부. 단 `.claude/launch.json`은 만들지 않는다 (승인 때 빠짐).
- **고칠 것**: `README.md`에 spec이 말한 3줄(앱 주소, 시안 주소, 내 컴퓨터에서 보는 법)만 덧붙인다.
- **손대지 말 것**: `design/`, `instructions/`, `CLAUDE.md`, `spec.md`. `review.md`도 만들지 않는다 (Review 서브에이전트 몫).
- git 커밋·푸시를 하지 않는다.
- spec과 다르게 만들어야 할 이유가 생기면 임의로 바꾸지 말고, 가장 spec에 가까운 방법으로 만든 뒤 보고에 "spec과 다른 점"으로 적는다.

1. `spec.md` 전체 — 특히 3장(기술 방식), 4장(파일 구조), 5장(라우팅), 6장(공통 요소, 6.2절 시안 CSS 옮기는 표), 7장(화면별), 8장(데이터), 9장(접근성·반응형·움직임), 10장(작업 순서), 11장(Review가 확인할 목록)

3. `design/DESIGN.md` — 토큰과 "하지 않을 것"

## 4. 승인된 결정 (spec 12장)

1. 빌드 없는 HTML·CSS·JS(ES 모듈), 외부 라이브러리 없음
2. 해시 주소 (`#/select` 등)
3. 게임 자리 화면 A안
4. 로그인 없이 보호된 주소로 오면 로그인 화면으로 보냄, 가짜 로그인은 탭 동안 기억
5. 마스코트 '비트' 유지 (학생 로그인 화면에만)
6. 보석 게임 설명은 '단어 보석' 방식
7. 이번 주 단어 ANIMALS 20개 (spec 8.5절)
8. 대시보드 학생 24명, 모두 지어낸 이름 (spec 8.4절)

## 6. 확인 방법 (이 컴퓨터 사정)

이 컴퓨터에서는 바탕화면 폴더에서 띄운 로컬 서버가 macOS 개인정보 보호 때문에 파일을 읽지 못한다. 그래서 **임시 폴더에 복사해서 띄운다.** 임시 폴더 위치는 작업 요청 메시지에 있다.

```bash
# 복사 (고칠 때마다 다시 실행)
rsync -a --delete --exclude .git "<프로젝트 폴더>/" "<임시 폴더>/build-site/"
# 서버 (임시 폴더 안에서, 백그라운드로 한 번만)
cd "<임시 폴더>" && python3 -m http.server 8701 --bind 127.0.0.1 --directory "<임시 폴더>/build-site"
```

- `curl`로 `index.html`, CSS, JS, `assets/favicon.svg`, `design/mockup.html`이 모두 200인지 본다.
- 자바스크립트 문법은 `node --check <파일>`로 하나씩 확인한다.
- 브라우저 도구가 있으면 `http://localhost:8701/`을 열어 확인한다: 화면 7종이 모두 그려지는지, 콘솔 오류가 없는지, 360 / 768 / 1280px 폭에서 가로 스크롤이 없는지, spec 5.4절의 화면 이동이 되는지.
- 끝나면 서버를 꼭 끈다.
